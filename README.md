# Phopee 📱

Phopee is an intelligent, interactive mobile phone recommendation engine built with React. By asking users a series of tailored questions about their budget, ecosystem preference, usage habits, and desired features, Phopee curates a personalized list of the best smartphones available in the market.

## Features ✨

- **Smart Recommendations:** Uses a custom scoring algorithm to match user preferences with the perfect smartphone.
- **Comprehensive Database:** Includes a wide range of phones from budget champions to ultra-premium flagships across all major brands (Apple, Samsung, Google, OnePlus, Xiaomi, Vivo, etc.).
- **Interactive Quiz:** A beautifully designed step-by-step quiz interface to gather user requirements.
- **Detailed Comparisons:** Compares recommended phones based on camera, performance, battery, and value.
- **Buying Links:** Provides quick links to popular e-commerce platforms (Amazon, Flipkart) and official brand stores for easy purchasing.
- **Modern UI/UX:** Features a sleek, responsive design with smooth animations and transitions, powered by React and modern styling techniques.

## Tech Stack 🛠️

- **Frontend Framework:** React 18
- **Build Tool:** Vite
- **Icons:** Lucide React
- **Styling:** Custom CSS/Tailwind (Integrated within the React App)

## Getting Started 🚀

Follow these steps to set up the project locally:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/phopee.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd phopee
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

### Running the Application

To start the development server, run:
```bash
npm run dev
```

Open your browser and navigate to the URL provided in the terminal (usually `http://localhost:5173`) to view the app.

## Build for Production 🏗️

To create a production build of the app, run:
```bash
npm run build
```

The optimized files will be generated in the `dist` folder.
